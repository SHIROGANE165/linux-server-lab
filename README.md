\# linux-server-lab



\## 概要



自宅PCの仮想環境上に小規模なサーバ運用環境を構築し、その過程を記録したリポジトリです。

資格学習（LinuC / CCNA）で得た知識を、実際に動くものとして残すことを目的としています。



手順の正解を示すものではなく、\*\*どこで詰まり、何を根拠に判断したか\*\*を残すことに重点を置いています。



\## 目的



\- 仮想マシン上でWebサーバを構築し、基本的な手順を身につける

\- 構築の過程を、第三者が追える形で記録する

\- 最終的にVPS上での構築へ移行し、ネットワークの知識を実環境に適用する



\## 環境



| 区分 | 内容 |

| --- | --- |

| ホストOS | Windows 11 Home 25H2 |

| CPU | AMD Ryzen 7 3700U (4コア8スレッド) |

| メモリ | 16GB |

| 仮想化ソフト | Oracle VirtualBox 7.2.6 |

| ゲストOS | AlmaLinux 10.2 (Lavender Lion) |

| VM構成 | vCPU 2 / メモリ 2048MB / ディスク 20GB (可変) |
